Questions, answered

Do I need an install for webcam face swap?

No install is needed for browser generation. For calls and streaming, route browser output through OBS. The Windows desktop app is optional.

Does generation happen only on my device?

No. Camera preview stays local, but generation sends your reference and camera stream to the model provider.

Is this the application source code?

No. This is a product introduction and static landing page. Use the official LiveSwap website to access the product.

Is LiveSwap.ai the same as liveswap.io?

No. This page is about LiveSwap.ai, not liveswap.io.

Create responsibly

Only use faces and references with permission. Do not impersonate people, deceive viewers or create abusive content. Disclose AI-generated output. LiveSwap output is labeled AI GENERATED · LiveSwap.
